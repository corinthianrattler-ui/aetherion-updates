# Aetherion Reforged v1.74.6

Major tournament and portrait-integrity update.

- Adds a persistent Valdara tournament circuit for all canonical main houses.
- Each house receives a lore-specific annual celebration plus one deterministic seeded random tournament per in-game year.
- Adds playable 8-person elimination brackets for armored duels, jousting, and archery.
- Integrates entry fees, purses, injuries, skill growth, house/Nobility reputation, company morale, tourney renown, trophies, and Grand Champion awards.
- Adds active-event buttons to Location Actions and a persistent Tournament Ledger to Systems.
- Uses the existing Aetherion tournament/joust/duel/archery artwork, routed through signed update assets.
- Repairs the v1.74.5 portrait leak: Quartermaster Edwyn Rook is matched only by his exact character id/name, while unrelated companions/workers return to the normal portrait resolver.
- Preserves the approved House Dominus sky-dial position in the open right-side HUD bay.

The update is schema-2 signed and cumulative from v1.74.5. The retired v1.74.5 portrait hotfix extensions are not carried forward.
